# Fichas rápidas exportadas (JSON) — alimentar IPAPD A/P/C

Salve aqui o JSON exportado de `painel/ficha_rapida.html`.

O dossiê por município (`Análise por município`) procura ficha cujo campo
`municipio` corresponde à localidade ativa e preenche os termos A/P/C do IPAPD.

Exemplos de exercício (não são eventos reais):

- `exemplo_manso.json` — Chapada dos Guimarães
- `exemplo_cuiaba.json` — Cuiabá (jusante Manso)
